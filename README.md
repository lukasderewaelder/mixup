# Teamlos (Arbeitsname)

Eine Teams-per-Zufall-App für den Unterricht: Namen eingeben, Gerät schütteln, faire Teams erhalten.
Läuft als PWA (iPhone, iPad, Android, Desktop), komplett offline, komplett auf Deutsch, ohne Konten und ohne Cloud.

**Stand:** Planungsphase – die Funktionen werden gerade mit der Spezifikation abgeglichen und hinterfragt.

- `planung/00-spezifikation-vorlage.md` – Ausgangs-Spezifikation (Vorlage, wird in der Planung überarbeitet)
- `planung/01-entscheidungen.md` – getroffene Entscheidungen je Fragenrunde
